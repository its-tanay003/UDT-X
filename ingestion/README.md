# UDT-X Ingestion Layer: Hardware TAP & One-Way Ingest NIC Architecture

> **Compliance: Section 16 & Section 26.4 (Fail-Closed, Read-Only Ingestion Boundary)**

This document details the configuration for deploying the UDT-X Ingestion Layer in high-security, physical or virtual network tap environments with strict **zero-egress guarantee**.

---

## 🔒 Security Guarantees

1. **Hardware & Kernel Enforced Read-Only TAP**:
   - The ingestion network interface (`<iface>`, e.g., `eth1`, `ens192`, `tap0`) operates strictly in receive-only mode.
   - All egress/outbound packets generated by the host or any process targeting the capture interface are dropped at the Linux Netfilter/iptables layer.
2. **Stealth Operation (No Active Probing / No Address Resolution)**:
   - Interface does **not** have an assigned default gateway.
   - ARP, DHCP, IPv6 Router Advertisements, and ICMP response mechanisms are disabled.
   - Attackers on the monitored network segment cannot discover or interact with the UDT-X sensor.

---

## ⚙️ Operating System & Interface Configuration

### 1. Disable Egress via iptables & nftables

Execute the following commands on the sensor host (replacing `eth1` with your dedicated capture interface):

```bash
# 1. Drop all outbound traffic originating from or traversing the capture NIC
sudo iptables -A OUTPUT -o eth1 -j DROP
sudo iptables -A FORWARD -o eth1 -j DROP

# 2. Block ARP announcements and responses on the capture NIC
sudo arptables -A OUTPUT -o eth1 -j DROP

# 3. For IPv6 environments, block all outbound IPv6 traffic on the interface
sudo ip6tables -A OUTPUT -o eth1 -j DROP
```

### 2. Interface Promiscuous & Stealth Configuration

Create a dedicated systemd network configuration or run manually:

```bash
# Bring interface up without an IP address
sudo ip link set dev eth1 up promisc on arp off

# Ensure no default gateway is associated with the capture interface
sudo ip route del default dev eth1 2>/dev/null || true

# Disable IPv6 autoconfiguration and link-local generation on capture NIC
sudo sysctl -w net.ipv6.conf.eth1.disable_ipv6=1
sudo sysctl -w net.ipv6.conf.eth1.autoconf=0
sudo sysctl -w net.ipv6.conf.eth1.accept_ra=0
```

### 3. Kernel Sysctl Hardening (`/etc/sysctl.d/99-udtx-tap.conf`)

Add the following parameters to ensure fail-closed stealth operation across reboots:

```ini
# /etc/sysctl.d/99-udtx-tap.conf

# Disable IP forwarding across interfaces
net.ipv4.ip_forward = 0

# Disable ICMP redirects
net.ipv4.conf.all.accept_redirects = 0
net.ipv4.conf.eth1.accept_redirects = 0
net.ipv4.conf.all.send_redirects = 0
net.ipv4.conf.eth1.send_redirects = 0

# Disable source routing
net.ipv4.conf.all.accept_source_route = 0
net.ipv4.conf.eth1.accept_source_route = 0

# Ignore ICMP echo broadcasts
net.ipv4.icmp_echo_ignore_broadcasts = 1

# Loose reverse path filtering for asymmetric TAP capture
net.ipv4.conf.eth1.rp_filter = 0
net.ipv4.conf.all.rp_filter = 0
```

Apply immediately:
```bash
sudo sysctl --system
```

## 📡 Ingestion Collector Modules

### 1. PCAP Ingestion Reader (`ingestion/pcap_reader/`)
- Reads raw `.pcap` or `.pcapng` files (stream-replayed or directory-watched).
- Performs 5-tuple flow aggregation, computes metrics (`bytes`, `packets`, `duration_ms`), extracts DNS queries, entropy, and TLS metadata.
- Publishes normalized records to Kafka topic `raw-events`.

```bash
# Run standalone:
python -m ingestion.pcap_reader.main --pcap /path/to/capture.pcap --kafka-brokers localhost:19092
```

### 2. NetFlow / IPFIX UDP Listener (`ingestion/netflow_listener/`)
- Async UDP listener on port `2055` (NetFlow v5/v9) and `4739` (IPFIX).
- Binary decoders unpack datagrams and stream canonical `FlowEvent` records directly to `raw-events`.

```bash
# Run standalone:
python -m ingestion.netflow_listener.server --port 2055 --kafka-brokers localhost:19092
```

### 3. Zeek Log Adapter (`ingestion/zeek_adapter/`)
- Streams Zeek JSON logs (`conn.log`, `dns.log`, `ssl.log`) and translates connection records to canonical format.

### 4. Suricata EVE Log Adapter (`ingestion/suricata_adapter/`)
- Normalizes Suricata `eve.json` events (both flows and signatures/alerts).
